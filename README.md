# anomaly-based-intrusion-detection-system
Real-time anomaly-based IDS built with Python and Machine Learning. Captures live packets using Scapy, extracts flow statistics, and uses a Random Forest model with heuristic thresholds to detect abnormal network behavior such as DoS and scanning attacks, generating alerts and logs.


## Dataset
The dataset used for training the intrusion detection model is not included in this repository due to its large size.

Dataset includes:
- Network traffic flow features
- Normal and anomalous traffic samples
- CSV formatted data used for model training

Dataset can be provided upon request.
